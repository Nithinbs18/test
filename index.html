🔊 Japanese pronunciation on iPhone

Try the audio test below. The built-in Listen/Slow buttons use the phone's Japanese speech voice. Each phrase also has an online pronunciation fallback that works without the browser's speech engine.

If there's no sound, open the actual webpage directly in Safari, not the GitHub code viewer or an in-app file preview. Check iPhone media volume and Bluetooth output, and install a Japanese voice in Settings → Accessibility → Read & Speak (or Spoken Content) → Voices → Japanese.

Backup: Tap “🌐 Hear online” beside a phrase. It opens that Japanese phrase in Google Translate, where you can tap the speaker. This works even when built-in Web Speech is blocked.

Restaurant tip: “vegetarian” alone may not exclude fish stock in Japan. For stricter vegetarian meals, also ask about 魚のだし (fish dashi) or かつおだし (bonito dashi).
